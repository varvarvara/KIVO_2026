# Репликация анализа

Независимая перепроверка выводов `analysis.ipynb` на очищенном массиве `data_clean.pkl` из `cleaning.ipynb`. Методы отличаются от основного анализа: расчёты на полных случаях, без восстановления пропусков; χ² с V Крамера, Краскел–Уоллис, корреляции Спирмена, логистическая регрессия.

## Файлы

| Файл | Содержание |
|---|---|
| `replication_report.md` | Отчёт: результаты, расхождения с основным анализом, ограничения |
| `presentation.pptx` | Презентация с результатами по гипотезам |
| `analysis_replication.py` | Все расчёты отчёта |
| `figures_replication.py` | Графики 01–11 в `figures/` |
| `figure_smoking.py` | График 12 (курение и оценки) |
| `pair_scan.py` | Перебор всех пар переменных в каждой волне с поправкой Бенджамини–Хохберга → `pair_scan_results.csv` |

## Запуск

Скрипты читают `data_clean.pkl` из корня репозитория (файл не хранится в git). Путь можно передать аргументом:

```bash
python replication/analysis_replication.py [путь/к/data_clean.pkl]
python replication/figures_replication.py [путь/к/data_clean.pkl]
python replication/figure_smoking.py [путь/к/data_clean.pkl]
python replication/pair_scan.py [путь/к/data_clean.pkl]
```

Зависимости: pandas, numpy, scipy, statsmodels, matplotlib.

## Расхождения с основным анализом

- Г2.3 (полный день → мысли об отчислении): на полных случаях без поправки на множественность связь значима (OR 2,0–2,6), в `analysis.ipynb` после поправки Холма — нет. В отчёте и презентации результат подан как неустойчивый.
- Остальные выводы совпадают по направлению и значимости.

## Дополнительно к основному анализу

- Перебор всех пар переменных: крупных связей вне набора гипотез не найдено.
- Курение связано с более низкими оценками в обеих волнах при контроле пола, направления, занятости, достатка, спорта, сна и алкоголя; изменения оценок между волнами не предсказывает (разведочный результат).
